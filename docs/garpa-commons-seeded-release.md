# GARPA Commons-seeded release verification

This stage converts only a publication-ready Commons package into one exact initial release bundle and verifies every generated byte before any public-release or registry claim may occur.

```text
qualified Commons-seeded publication
  + publication_ready from the existing publication gate
  + deterministic required release files
  + exact SHA-256 and UTF-8 byte lengths
  + exact R1 current manifest
  + existing release-manifest verifier
  + existing release-bundle verifier
  -> Commons release-custody gate
  -> current_valid verified candidate bundle
```

The bundle includes the release metadata, README, reality brief, public dossier, complete publication claims, support graph, failure register, residual register, publication-gate receipt, Commons publication receipt, rights review, safety review, redactions, vendor-parity receipt, mission-evaluation receipt, and vendor artifact ledger. Every file is mandatory and content-derived from the admitted publication result.

The gate recomputes every UTF-8 byte length and SHA-256 digest, rejects unsafe or duplicate paths, refuses unmanifested files, and compares every submitted file with deterministic generated content. It then delegates to both existing release verifiers.

Version 1 admits only the initial current R1. It does not invent prior-release or supersession lineage. Later correction, withdrawal, or supersession must carry a separate custodied predecessor release and registry transition.

Release verification establishes candidate-bundle integrity only. It does not mean that public release occurred, the registry was updated, deployment was authorized, or unrestricted equivalence was established.
