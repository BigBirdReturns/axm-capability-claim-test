# GARPA method version

Current branch method version: `0.8.0-commons-seeded-build-manifest`.

The highest governed stage freezes an exact target build manifest after a Commons-seeded qualification contract reaches the existing qualification gate. Every seeded component remains bound to its exact Commons source, frozen qualification binding, architecture selection and configuration, target manifest component, no-substitution policy, qualification regressions, calibration or preassembly verification work, and every assembly step that touches it. The existing build-manifest validator and gate remain authoritative for target-only components, custom code, compatibility edges, human roles, dependencies, instrumentation, calibration, substitution policy, assembly sequencing, and architecture cost and schedule trace.

Automatic physical execution is not implemented or authorized. Seeded build-manifest admission does not transfer source runs, pass states, calibration, authority, qualification, compatibility, deployment fitness, vendor parity, publication authority, or mission equivalence. A passing result authorizes controlled assembly under the frozen manifest only. Installed identity, substitutions, calibration, deviations, and integration must still be proven by an as-built receipt before preflight or test authority can exist.
