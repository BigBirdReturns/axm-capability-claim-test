# GARPA method version

Current branch method version: `1.7.0-commons-seeded-external-publication-receipt`.

The highest governed stage is `commons_seeded_external_publication_receipt`. It recomputes the exact admitted public-registry result, binds the current release, complete registry entry, external receipt, locator, event kind, publisher, observation window, and content-addressed capture artifacts, and delegates event semantics to the ordinary external-publication receipt gate.

Synthetic qualification receipts remain explicitly qualification-only and cannot assert a real event. An observed external receipt proves only the exact recorded publication or distribution event. Neither evidence class establishes deployment authority or unrestricted product equivalence.
