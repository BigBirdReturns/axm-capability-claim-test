# Commons-seeded external-publication qualification example

The generated files in this directory exercise the external-publication receipt mechanism with `evidenceClass: synthetic_qualification`.

The example is deliberately not an observed external event. Its locator uses the `fixture://` scheme, `syntheticQualificationOnly` is true, and `externalEventObserved`, `publicRegistryPublished`, and `publicReleaseOccurred` remain false.

A real observed event requires a separately supplied non-synthetic locator and captured evidence bytes bound to the exact qualified registry entry and current verified release.
