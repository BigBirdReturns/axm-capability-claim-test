# GARPA-0001 intake fixture — Vectus

This fixture captures the visible claims in a Swarmer launch-post screenshot and
proves the first GARPA refusal state. The post is sufficient to identify the
offering, advertised outcome, claimed mechanism, and advertised economics. It
is not sufficient to select an architecture because the exact version,
operator record, operating environment, system boundary, numerical baseline,
time and coverage requirement, and falsifiable success threshold remain open.

The expected admission result is `goal_hypothesis`, with
`architectureReady=false`. The fixture does not model or authorize any active
countermeasure.
