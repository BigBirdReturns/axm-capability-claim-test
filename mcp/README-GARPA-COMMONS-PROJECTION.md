# GARPA Commons component-projection MCP server

Run locally:

```bash
cd mcp
npm ci
npx tsx garpa-commons-projection-server.ts
```

Tools:

```text
validate_garpa_commons_component_projection
run_garpa_commons_component_projection
```

The server can emit target `ComponentCandidate` records only when the target case supplies exact-version evidence for identity, performance, availability, price, and licensing. It does not transfer source qualification, compatibility, substitution coverage, architecture, procurement, testing, deployment, or equivalence.
