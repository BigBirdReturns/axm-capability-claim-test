# GARPA Commons-seeded publication MCP

```bash
npx tsx garpa-commons-seeded-publication-server.ts
```

Tools:

- `validate_garpa_commons_seeded_publication`
- `run_garpa_commons_seeded_publication`

The server recomputes the complete mission and parity chain, regenerates the exact public-claim package, verifies rights, safety, redaction, audience, case-index, and artifact custody, and returns the existing publication gate's ready or blocked state. It does not establish immutable release integrity, registry currency, deployment authority, or unrestricted equivalence.
