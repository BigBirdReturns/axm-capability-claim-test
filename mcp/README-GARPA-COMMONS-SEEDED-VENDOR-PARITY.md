# GARPA Commons-seeded vendor-parity MCP

```bash
npx tsx garpa-commons-seeded-vendor-parity-server.ts
```

Tools:

- `validate_garpa_commons_seeded_vendor_parity`
- `run_garpa_commons_seeded_vendor_parity`

The server recomputes the complete target mission campaign, derives the GARPA comparison observations from the frozen qualification methods, verifies exact-version vendor evidence custody, and returns the existing evaluator's bounded parity state. It does not establish unrestricted product equivalence, deployment authority, or publication authority.
